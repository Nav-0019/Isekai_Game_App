## 🌌 Overview

Inspired by the "System" mechanics of modern cultivation and Isekai manhua, the **Isekai Game App** is a high-fantasy RPG experience built from scratch. Whether you are navigating a treacherous web-based dungeon or the mobile frontier, your goal remains the same: match monster numbers, upgrade your arsenal, and rise through the ranks to defeat the final boss.

-----

## 🎮 Core Gameplay Mechanics (The "System")

The game operates on a logic-driven progression system designed for tactical engagement:

  * **Monster Matching:** Defeat enemies by matching attack numbers, a core mechanic that tests both speed and strategy.
  * **Rank Progression:** Advance from a low-tier adventurer to an immortal-class warrior.
  * **Weapon Evolution:** Unlock and upgrade weapons as you clear harder stages.
  * **The Final Boss:** A high-stakes encounter that requires the culmination of your leveled-up stats and equipment.

## 🚀 Installation & Setup

### For the Web Version

1.  Clone the repository:
    ```bash
    git clone https://github.com/Nav-0019/Isekai_Game_App.git
    ```
2.  Open `index.html` in your browser.

### For the Android (Kotlin) Version

1.  Import the project into **Android Studio**.
2.  Build the project and run on an emulator or physical device.
